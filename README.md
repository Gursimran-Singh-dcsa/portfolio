# Gursimran Singh — Portfolio

Next.js (static export), TypeScript, styled only with Tailwind CSS v4, installable as a PWA.

```bash
npm install
npm run dev       # local dev
npm run build     # type-check + production build
npm run deploy    # publish out/ to the gh-pages branch (gursimran.in)
```

See `CLAUDE.md` for how to add projects and blog posts.
